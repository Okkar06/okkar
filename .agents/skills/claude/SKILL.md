# claude
## When to Use
Activate for open-ended questions, writing, summarisation, explanation, coding help, brainstorming, and reasoning tasks.

## Commands
Call the Claude API endpoint with the user's prompt as the message content.

## Output
Return Claude's response text directly to the user.
